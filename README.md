# Shotgun Conjectures

Resolutions of open questions and conjectures from four collections, found by
an AI-assisted scan (Claude agents, 2026). **Everything here is AI-generated.
Each item states how far it has been checked; treat unreviewed items as
claims, not results.**

| directory | source |
|---|---|
| [`OEIS/`](OEIS/README.md) | conjecture comments in the On-Line Encyclopedia of Integer Sequences |
| [`NT/`](NT/README.md) | R. K. Guy, *Unsolved Problems in Number Theory*, 3rd ed., Springer 2004 |
| [`GEO/`](GEO/README.md) | H. T. Croft, K. J. Falconer, R. K. Guy, *Unsolved Problems in Geometry*, Springer 1991 |
| [`COM/`](COM/README.md) | M. Coman, *Two Hundred Conjectures and One Hundred and Fifty Open Problems on Fermat Pseudoprimes*, 2013 |
| [`methods/`](methods/README.md) | the proof methods, in general form, with the library code |

Each group README has a table of all its entries (statement, result, Lean
status, method) and the short proofs written out.

## Layout

```
<SRC>/README.md                 table of the group + short proofs (generated)
<SRC>/<ID>/README.md            source, reading, result, argument, evidence, review level, prior art
<SRC>/<ID>/<M>.lean             core-Lean check (no imports)
<SRC>/<ID>/<M>_mathlib.lean     Lean + Mathlib proof (imports Mathlib and lib/)
<SRC>/<ID>/certificate/         scripts, witnesses, logs
methods/<method>/README.md      one proof method (YAML front matter + text)
methods/oplib/                  Python library for the methods
problems.jsonl                  index, one JSON object per problem
DATA.md                         external tables some certificates read
lib/OpenProblemsLib/            shared Mathlib library: binary powMod, Pratt primality
                                certificates, Fermat pseudoprime checks, Korselt, Cipolla
tools/leancheck.sh              checks core-Lean files one at a time (memory-capped)
tools/leancheck-mathlib.sh      checks Mathlib files; tools/buildlib.sh compiles lib/
tools/pratt_cert.py, lean_expand.py, family_lean.py   generate certificates and Mathlib files
tools/manifest.py, build_readmes.py   regenerate the index and the generated READMEs
```

Problem directories are named by the source's own label (`OEIS/A100682`,
`NT/E29.1`, `COM/C125`, `GEO/C2.2`); `problems.jsonl` uses ids of the form
`OEIS-A100682`. Some certificate READMEs mention `../open-problems/...`: that
is the scan repository (triage of all 3184 problems), which is separate.

## Review levels

| level | meaning |
|---|---|
| `agent` | produced by one agent; not independently checked |
| `rechecked` | re-derived or recomputed independently (method stated in the README) |
| `lean-witness` | the finite facts are checked in Lean; any remaining step is named in the README |
| `lean-proof` | the full statement is proved in Lean (axioms listed) |

## Novelty

`prior_art_search: false` means nobody has searched the literature beyond
checking the current OEIS entry or a quick web search. Some items will turn
out to be known. Corrections welcome.

"Paper only" items were re-derived by a second reader; "needs Mathlib" names
the ones whose formalisation needs Mathlib (primality certificates,
Korselt's criterion in general, Dirichlet's theorem, real analysis).
All 167 core-Lean files, 146 Mathlib proof files and the 2 library tests check with Lean 4.35.0 and
Mathlib revision 56a0058 (2026-11-04), with no warnings; each file's header
states what it does and does not check, and `#print axioms` gives only
`propext`, `Quot.sound` and `Classical.choice`. Primality of large numbers is
proved in Lean by Pratt certificates (`lib/OpenProblemsLib/Pratt.lean`,
sound by Mathlib's `lucas_primality`), evaluated by the kernel with
`decide +kernel`.

Checking the Mathlib files: the local checks ran `lean` with `LEAN_PATH`
pointing at a prebuilt Mathlib of that revision (`tools/leancheck-mathlib.sh`,
`tools/buildlib.sh`). `lakefile.toml` pins the same revision for the usual
route (`lake exe cache get`, `lake build`, `lake env lean <file>`); that
route has not been run here. "Disputed" items were
corrected (the scan's verdict changed), not left wrong.
