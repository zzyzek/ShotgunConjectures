# OEIS A162311: alternation for t(n) = t(n+7)

Shevelev's conjecture (odious and evil solutions of A010060(n) = A010060(n+k) alternate, for fixed
odd k); this entry is k = 7. Known (see the A161890 comment); proved for every odd k, with a Lean
proof (`alternate_eq`), in [`../A161579`](../A161579/README.md).
