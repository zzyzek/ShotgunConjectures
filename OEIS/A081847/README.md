# OEIS A081847: see A082235

The conjecture "every triangular number other than 3, 6 and 10 is a member" stated in A081847 refers to
A082235 (concatenations of successive terms of A081847). It is false (1, 21, 28, 45, 78, 91 are never hit);
proof and Lean file in [`../A082235/`](../A082235/README.md).
