# OEIS A132870: see A177390

The conjecture "for all integer k there exists an integer triangle J with row n of J^(kn) having
g.f. (k n^2 + y)^n" fails at k = 1, which is this triangle: T(30,0) is not an integer (already
noted in the entry by M. F. Hasler, 2017). Write-up, Lean witness and certificate:
[`../A177390/`](../A177390/README.md).
