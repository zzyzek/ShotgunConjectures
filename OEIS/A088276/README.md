# OEIS A088276: 10^k + 9351 is never prime, though 9351 ≡ 0 (mod 3)

**Source.** [A088276](https://oeis.org/A088276) (smallest k with 10^k + r a prime ending in r, r the n-th
odd number not divisible by 5, offset 0; 0 if none), comment: "Conjecture: (1) The only zero entries are for
values of r == 2 (mod 3). (2) There are infinitely many values of k such that 10^k + r is a prime if r is not
== 2 (mod 3)." (OEIS text, CC BY-SA 4.0.)

**Result.** Both false at r = 9351 (index n = 3740 with the entry's offset 0; the scan's note said 3741,
which is the 1-based position). Further covered r found by the scan: 46927, 48247, 56473, 61863.

**Argument.** Covering congruences with period 6: 7 | 10^k + 9351 for k ≡ 0 (mod 6), 11 for k odd,
13 for k ≡ 2 (mod 6), 37 for k ≡ 1 (mod 3). These cover every k, and 10^k + 9351 > 37.

**Evidence.**
- Lean: [`A088276.lean`](A088276.lean) (generated by `oplib.lean.covering_file`): for every k a covering
  prime divides 10^k + 9351 and is smaller.
- Lean + Mathlib: [`A088276_mathlib.lean`](A088276_mathlib.lean), `A088276_main`: the 3740-th (0-indexed)
  odd number not divisible by 5 (`Nat.nth`) is 9351, 9351 ≡ 0 (mod 3), and 10^k + 9351 is never prime;
  `A088276_conj1_false`, `A088276_conj2_false` negate both conjectures. Outside Lean: nothing.
- `certificate/check.py` (index, cover, direct k ≤ 3000); `covering.gp` (scan search).

**Review level.** `lean-proof`: both conjectures refuted at index 3740, in [`A088276_mathlib.lean`](A088276_mathlib.lean).
**Prior art.** Known: [Prime Puzzles 556](https://www.primepuzzles.net/puzzles/puzz_556.htm) (Clark, Tomita and others) shows 10^n + p composite for all n when p == 9351 (mod 37037) via {7, 11, 13, 37}, and also for 48247 and 56473.
