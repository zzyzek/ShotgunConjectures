# OEIS A002383: A002383 \ {3} = A085104 ∩ A059055 (open; inclusion ⊆ proved)

Treated together with A007645; see [`../A007645/README.md`](../A007645/README.md). The inclusion ⊆ holds
(`A002383_sub` in [`../A007645/A007645_mathlib.lean`](../A007645/A007645_mathlib.lean)). The inclusion ⊇ is
equivalent to a negative-base Goormaghtigh statement (no prime (n^q-1)/(n-1) = (b^r+1)/(b+1) with odd q, r >= 5
outside A002383) and is open; no coincidence with q, r >= 5 exists below 10^26.
