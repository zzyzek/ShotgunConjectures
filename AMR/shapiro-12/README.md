# AMR shapiro-12: Forsgård–Shapiro Conjecture 9 (c̃_k parity bound) is false

Known: Katkova, Shapiro and Vishnyakova (arXiv 2403.12200, Section 5) refute it. This repo
gives a single degree-24 counterexample with 22 distinct zeros and v~ = 20. It also refutes
Conjectures 8 and 10, and it is checked in Lean. See [../shapiro-11/README.md](../shapiro-11/README.md).
