# Identify Nat.nth of a Diophantine set

**When it applies.** One side of the claim is `Nat.nth p` for a Diophantine predicate p, the other an explicit
strictly increasing sequence f.

**Method.** Show that the range of f is exactly {m | p m}, usually through a classification of the solutions
of a Pell equation (descent, see `units-pell`), then apply
`Nat.eq_nth_of_strictMonoOn_of_mapsTo_of_surjOn` to get `Nat.nth p k = f k`.

**Worked example.** [OEIS/A195538](../../OEIS/A195538/README.md) (A046090, A076218); also OEIS/A195539 (A046176).
