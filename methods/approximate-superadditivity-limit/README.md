# Limits from approximate superadditivity at dyadic sizes

**Origin.** Drafted 2026-11-05 from the OpenAI mathematics manuscript collection (github.com/openai/math, snapshot 2026-10-26), families OAI 235, OAI 234, OAI 221. Paraphrased from abstracts and skimmed proofs; not yet used on a problem in this repo. Confidence that this is one technique: medium (235 explicit; 234/221 use Guerra-type interpolation, a relative)

**Method.** Compare the size-2n system with two independent size-n systems (by interpolation, clause replacement or concatenation) to get c(2n) >= c(n) - e(n); if the errors are summable along n, 2n, 4n,..., the normalised values converge. Concentration and monotonicity fill in non-dyadic n. A computable-limit variant adds lower certificates (deletion) and upper certificates (finite relaxations) searched fairly.

**Fit to small problems.** yes: the deterministic lemma is elementary and applies to OEIS conjectures that a(n)^(1/n) or a(n)/n converges when a near-superadditive comparison is available.

**Lean examples (OpenAI repo).** `lean/OAI/Probability/RandomSAT`
