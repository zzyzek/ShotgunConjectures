# Exact evaluation of real-valued statements

**When it applies.** Floors of roots, comparisons like n! vs m^m, "nearest x".

**Method.** Rewrite each floor or comparison as an integer inequality and evaluate exactly. Failures of a
floor formula sit near continued-fraction convergents of the irrational constant: search there.

**Certificate.** The integer inequalities at the witness; `decide` checks them in Lean.

**Pitfalls.**

- Floating point gives wrong answers exactly at the interesting points.

**Code.** `methods/oplib/exact.py`

**Worked example.** [OEIS/A100682](../../OEIS/A100682/README.md), Lean [OEIS/A100682/A100682.lean](../../OEIS/A100682/A100682.lean)
