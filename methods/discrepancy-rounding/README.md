# Relax then round by discrepancy

**Origin.** Drafted 2026-11-05 from the OpenAI mathematics manuscript collection (github.com/openai/math, snapshot 2026-10-26), families OAI 076, OAI 097. Paraphrased from abstracts and skimmed proofs; not yet used on a problem in this repo. Confidence that this is one technique: high (both PDFs read)

**Method.** First solve the problem with real coefficients in [-1,1] (a smooth construction, often with stationary-phase control), arranged so most coefficients are already near +-1. Then round with partial colouring (Beck-Spencer, Lovett-Meka) or Banaszczyk-type vector balancing; the rounding error is bounded by the total defect sum(1-|x_k|), not by N. A finished argument has the relaxed construction, the defect bound and the rounding lemma.

**Fit to small problems.** yes: directly for +-1 sequence problems (Littlewood flatness, merit factor, Erdos discrepancy variants); Lovett-Meka is implementable for N up to 10^4-10^5.

**Lean examples (OpenAI repo).** `lean/OAI/Analysis/Littlewood`, `lean/OAI/Analysis/Steinitz`
