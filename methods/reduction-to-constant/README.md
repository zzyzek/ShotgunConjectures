# Congruence reduction to a constant

**When it applies.** "Infinitely many Carmichael numbers / pseudoprimes of the form p·g(p)".

**Method.** For a prime factor p, Korselt's criterion needs p − 1 | N − 1, and N − 1 ≡ g(1) − 1 (mod p − 1).
So p − 1 divides the fixed number g(1) − 1: finitely many p, test each. For base-2 pseudoprimes reduce
modulo ord_p(2) the same way. General form: a condition f(p) ≡ 0 (mod p − 1) with f polynomial becomes
divisibility of the constant f(1).

**Certificate.** The constant, its divisors p, and the test of each candidate.

**Pitfalls.**

- The converse direction (Korselt implies Carmichael) needs squarefreeness; state it.

**Code.** `methods/oplib/carmichael.py (korselt_constant, candidates_from_constant)`

**Worked example.** [COM/C116](../../COM/C116/README.md), Lean [COM/C116/C116.lean](../../COM/C116/C116.lean)
