# Density / union bound

**When it applies.** "Infinitely many n such that n − f(k) avoids P for all k", "every n is a sum of two numbers of type T".

**Method.** Fix residues modulo p² (or p) for small primes by CRT so those primes never interfere; bound the
remaining bad density by a sum over k and large p (≤ K·Σ_{p>z} 1/p²); choose z so the bad fraction is
below 1. First-moment bounds on σ(n)/n do the same for abundance.

**Certificate.** The CRT residues, the explicit tail bound, and the numeric constant showing the bad fraction < 1.

**Pitfalls.**

- Needs explicit prime-sum tail bounds (Rosser–Schoenfeld); cite them.
