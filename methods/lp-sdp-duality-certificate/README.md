# LP / SDP / SOS dual certificates

**Origin.** Drafted 2026-11-05 from the OpenAI mathematics manuscript collection (github.com/openai/math, snapshot 2026-10-26), families OAI 090, OAI 266, OAI 182, OAI 342, OAI 367, OAI 373, OAI 204, OAI 222, OAI 175. Paraphrased from abstracts and skimmed proofs; not yet used on a problem in this repo. Confidence that this is one technique: medium (090 and 266 clear; others share only the duality framing)

**Method.** Write the bound as the value of a convex program over correlation functions or moments; exhibit a dual feasible object (an auxiliary radial function with nonnegative Fourier transform, a sum of squares, a reflection-positive law, a positive current) that matches the conjectured extremiser. Optimality follows from weak duality; exactness needs the dual object to vanish on the extremiser support. A finished argument contains the dual object and a rigorous check of its constraints.

**Fit to small problems.** yes: Delsarte LP / Lovasz theta / flag-algebra style bounds for small codes and designs; our interval-layer-lp is an instance.

**Lean examples (OpenAI repo).** `lean/OAI/Analysis/PlanarPacking`, `lean/OAI/Analysis/MutuallyUnbiased`
