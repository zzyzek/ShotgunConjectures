# Selberg sieve for polynomial values in Lean

**Method.** Apply the Selberg Lambda^2 sieve (PrimeNumberTheoremAnd's `SelbergSieve`, inlined) to the values of a polynomial, e.g. n(n + h).
- Local densities: count roots mod d with `Nat.card` over `ZMod d`; multiplicative by the Chinese remainder theorem.
- Remainders by periodicity: #{n < N : d | P(n)} = rho(d) floor(N/d) + E with |E| <= rho(d) <= d.
- Main term from any completely multiplicative f with f(p) <= nu(p) (x/(1 - x) is increasing), then a harmonic-sum lower bound with the primes of h removed one at a time.
- Error with |mu+(d)| <= 3^omega(d) <= d^2 at level Y = w^4.
Changing the root count gives other pairs of linear forms and prime k-tuples.

**Worked example.** [FAM/twin-primes](../../FAM/twin-primes/README.md)
