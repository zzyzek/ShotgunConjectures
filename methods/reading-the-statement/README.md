# Pin the statement before solving

**When it applies.** Any problem. Especially OCR text, OEIS offsets, informal wording ("distinct", "surrounded", "abuts").

**Method.** Recover the exact statement, convention and index offset. Reproduce every number the source states
(small values, exception lists, known thresholds) with your own encoding before trusting a result.
If the source's numbers cannot be reproduced, either the encoding or the source is wrong; record which
reading is used in a **Reading** section.

**Certificate.** A **Reading** paragraph naming the convention, plus the reproduced source numbers.

**Pitfalls.**

- OEIS-A100682: the conjecture uses floor(C(n,4)^(1/4)) while the entry defines floor(C(n+3,4)^(1/4)); the intended reading is the one reproducing the author's exception list.
- Guy E29: "x, y, x+y, xy distinct" vs Graham's 252 (x = 1 allowed, x < y): only x < y reproduces 252.
- Second readers overturned 7 of ~270 verdicts here; most came from reading, not mathematics.

**Worked example.** [OEIS/A100682](../../OEIS/A100682/README.md)
