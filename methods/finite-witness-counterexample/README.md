# Finite witness for a continuous or asymptotic conjecture

**Origin.** Drafted 2026-11-05 from the OpenAI mathematics manuscript collection (github.com/openai/math, snapshot 2026-10-26), families OAI 088, OAI 100, OAI 118, OAI 155, OAI 156, OAI 161, OAI 162, OAI 172, OAI 187, OAI 190, OAI 272, OAI 329. Paraphrased from abstracts and skimmed proofs; not yet used on a problem in this repo. Confidence that this is one technique: high (the move is explicit in 156, 161, 162, 187; others medium)

**Method.** Reduce the universal claim to a property of one finite object, then build that object (by search, finite geometry or hand design) and check the property exactly. The reduction is the real idea: Borsuk covers of rank-one projectors become colourings constrained by orthogonal pairs (156); Ryser covers become a modified affine plane over F_q (162); a Sidorenko violation becomes a 13-point pair-doubling triple system (161); bin-packing LP gaps become instances with all items above 1/6 (118); the Snaky game becomes a game tree with reusable templates (187). A finished argument contains the reduction lemma, the object, and an exact verification (ILP, SAT, exact rational arithmetic or a Lean decide proof).

**Fit to small problems.** yes: same shape as our explicit-counterexample and sat-threshold work, but the reduction step (continuous to finite) is the transferable part; e.g. Erdos/Guy covering and colouring questions whose extremal object is a finite geometry.
