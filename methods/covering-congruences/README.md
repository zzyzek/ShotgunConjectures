# Covering congruences

**When it applies.** "A·b^n + C is prime for some n", "for every x there is n with F(x, n) prime", families k·2^n ± 1, p + 2^n.

**Method.** Take primes q with ord_q(b) dividing L. Each gives one class of n mod ord_q(b) on which q divides F(n).
Choose classes covering Z/L. For a free parameter x (F affine in x) each class is one residue of x mod q;
combine by CRT and search the progression for x meeting the side conditions (x prime, x a pseudoprime, ...).
General form: any family whose divisibility by q is periodic in n with period dividing L.

**Certificate.** The list (q, ord_q(b), class), L, the witness x, and F(n) > max q so each divisor is proper. In Lean: finitely many `decide` facts plus one periodicity lemma prove "for every n".

**Pitfalls.**

- When x must lie in a sparse set (Carmichael numbers) the cover only yields a progression; existence then needs a density theorem in progressions (Larsen 2025), making the result conditional.

**Code.** `methods/oplib/covering.py`, `methods/oplib/lean.py (covering_file generates the Lean proof)`
