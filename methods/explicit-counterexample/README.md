# Explicit counterexample

**When it applies.** "Every n ...", "the only solutions are ...", "X is always prime/composite", "no n with ...".

**Method.** Search directly for a witness, guided by structure (small primes, factor patterns, near-misses of the
claimed formula). One verified witness refutes the claim. Check the witness with arithmetic independent
of the search code.

**Certificate.** The witness, its factorization or defining data, and an independent check (ideally a Lean `decide` theorem).

**Pitfalls.**

- A witness found by a buggy encoding refutes nothing: re-check from the definition, not from the search code.
- Primality of large factors is not checked by core Lean `decide`; state it as outside Lean.

**Code.** `methods/oplib/lean.py (LeanFile.eq/.factor/.bool_true)`

**Worked example.** [OEIS/A212843](../../OEIS/A212843/README.md), Lean [COM/C044/C044.lean](../../COM/C044/C044.lean)
