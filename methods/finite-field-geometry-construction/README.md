# Finite-field and finite-geometry constructions

**Origin.** Drafted 2026-11-05 from the OpenAI mathematics manuscript collection (github.com/openai/math, snapshot 2026-10-26), families OAI 157, OAI 160, OAI 161, OAI 162, OAI 172, OAI 196, OAI 329. Paraphrased from abstracts and skimmed proofs; not yet used on a problem in this repo. Confidence that this is one technique: medium-high (the families share the F_q-structure move but differ in what is counted)

**Method.** Use the incidence structure of an affine/projective plane, multilinear or symmetric forms over F_p, or cell decompositions of Z/q^D to get an object whose key counts are exactly computable by character sums or linear algebra; then modify it locally (merge or split parallel classes, take half-rank kernels, add outer colours) to break the conjectured inequality. A finished argument has the construction, the exact count of the controlling quantity, and the local modification lemma.

**Fit to small problems.** yes: small-q instances are finite and checkable by ILP or SAT; matches Guy-type problems on designs, covering and colourings.
