# Invariant for greedy sequences

**When it applies.** a(n) is the least unused m with some admissibility condition depending on earlier terms.

**Method.** Prove a lemma that ranks the admissible candidates by a size parameter (A165300: the admissible
numbers are the alternating 1/2 numbers with the right first digit, ordered by length). Then carry, by induction
over blocks of a few steps, an invariant describing the set already used; read off a closed form for each
residue class of n, and the conjectured rules from the closed form.

**Worked example.** [OEIS/A165300](../../OEIS/A165300/README.md).
