# Lean certificates in core Lean

**When it applies.** Any result whose evidence is a finite object or a finite computation, plus "for every n" claims reducible to finitely many facts and a periodicity lemma.

**Method.** Write a Bool checker in core Lean over data lists and close it with `decide` (the kernel has GMP
arithmetic); explicit factors for compositeness; inequalities of big numbers. Bound every search by an
explicit constant. "For every n" via periodicity: prove the finite facts by `decide` and lift with a
lemma like b^n mod q = b^(n mod o) mod q.

**Certificate.** The Lean file, its axioms (`#print axioms`), and a header stating what is not checked.

**Pitfalls.**

- `decide` over `List.range (n+1)` with n in the hundreds hits the kernel recursion limit; bound by a literal.
- Primality of large numbers needs a certificate and Mathlib.
- Never `native_decide`: it trusts the compiler.

**Code.** `methods/oplib/lean.py`, `tools/leancheck.sh`

**Worked example.** [COM/C125](../../COM/C125/README.md), Lean [COM/C125/C125.lean](../../COM/C125/C125.lean)
