# Layer LP with interval constraints

**When it applies.** Bounding the largest code in a graph on binary words whose conflicts are invariant under coordinate permutations and join only words whose weights differ by at most one (so weight layers form a chain), e.g. Z-channel codes.

**Method.** Work with layer sizes a_w. Constraints: (1) averaged cliques (a word with its one-up or one-down neighbours); (2) exact maxima of codes restricted to a window of consecutive weights (small integer programs); (3) interval rows: every interval [T, Z] of the Boolean lattice is a copy of a smaller cube with the same conflicts, so the code meets it in a smaller code; averaging the small window maxima over all intervals of a type gives sum_w a_w C(w,t) C(n-w, t+m-w) <= W_m(j1,j2) C(n,t) C(n-t,m). The LP optimum bounds the code size; recursing (bounds at length m feed length m+1) and iterating to a fixpoint tightens it.

**Certificate.** The LP dual: a few rows with rational multipliers whose combination gives coefficient >= 1 on every a_w; plus proofs of the window maxima it uses.

**Pitfalls.**

- Window maxima computed with the end words fixed (simplicial reduction) are valid only for windows that count those words.
- The method reproduces older LP bounds exactly where it does not improve them; the gain comes from exact window data.
