# Scan a complete table

**When it applies.** Universal or uniqueness claims about pseudoprimes, Carmichael numbers or sequence terms: "every Carmichael number ...", "the only ... are", "are there others besides ...".

**Method.** Stream a table known to be complete below a bound and test the claim on every entry: the
Feitsma–Galway base-2 pseudoprimes below 10^13, Pinch's Carmichael numbers below 10^21, OEIS b-files.
A failure is a counterexample; no failure is evidence up to the bound (not a proof of an infinite claim).

**Certificate.** Table name and bound, the script, its output (count scanned, exceptions found).

**Pitfalls.**

- Say which table and bound; "no exception" is never a proof of a claim about all n.
- Tables are external (see DATA.md); scripts read them from data/.

**Code.** `methods/oplib/carmichael.py (stream_psp2, stream_carmichael), methods/oplib/oeis.py (bfile)`

**Worked example.** [COM/C019](../../COM/C019/README.md)
