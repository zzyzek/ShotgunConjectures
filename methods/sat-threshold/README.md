# Incremental SAT threshold

**When it applies.** "Least N such that every colouring / arrangement of [1, N] ...", existence of a small combinatorial object.

**Method.** Encode "an object of size N exists" with clauses that only grow with N; increase N on one incremental
solver. At the threshold: re-check the last satisfying assignment with an independent checker written from
the definition, cross-check UNSAT with several solvers, and check a DRAT proof with a checker that did not
produce it.

**Certificate.** The model below the threshold (checked from the definition), the CNF, a DRAT proof and the checker log.

**Pitfalls.**

- The encoding is the weak point: regenerate the CNF independently and compare clause sets.
- Solver agreement is not a proof; the DRAT check is.

**Code.** `methods/oplib/sat.py`, `NT/E29.1/certificate/rupcheck.c (DRAT checker)`

**Worked example.** [NT/E29.1](../../NT/E29.1/README.md)
