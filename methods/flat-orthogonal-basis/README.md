# Flat orthogonal basis (Fourier, Hartley, Hadamard)

**Method.** The vertices of a regular simplex are the rows of an orthogonal n×n matrix after the constant column
is removed (scaled by 1/√2 for edge 1). Choose that orthogonal matrix flat: every entry is O(1/√n).
- The real Fourier basis and the Hartley matrix cas(2πkt/n)/√n (cas x = cos x + sin x) work for every n, with
  entries at most √(2/n).
- A Hadamard matrix gives entries exactly ±1/√n, but only for orders where one exists.

The simplex then fits in a box of side O(1/√n), and translating it on a grid packs exponentially many copies.

**Lean.** Orthogonality of the Hartley matrix follows from sums of n-th roots of unity (IsPrimitiveRoot,
geom_sum). The same orthogonality gives affine independence, and with it nonempty interior through
`interior_convexHull_nonempty_iff_affineSpan_eq_top`. Without nonempty interior a "disjoint interiors" packing
statement is vacuous, so prove it.

**Pitfalls.** The flat-matrix step gives edge √(d+1)/2 in the unit cube. The optimum is √((d+1)/2), reached
exactly when a Hadamard matrix of order d+1 exists, so the constant is off by √2.

**Worked example.** [BMP/1.8.7](../../BMP/1.8.7/README.md) (Moser's simplices in a cube).
