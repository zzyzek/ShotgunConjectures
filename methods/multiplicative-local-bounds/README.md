# Local bounds for multiplicative counts

**When it applies.** f is multiplicative on coprime arguments (here by the Chinese remainder theorem) and the
claim classifies the n where f(n) reaches a target such as n/3 + 1.

**Method.** Avoid exact prime-power values; use bounds that hold for every exponent.
- Upper bounds from collisions: x and m − x, or 0 and m/d, give the same value, so f(m) ≤ m/2 + 1, and
  f(m) ≤ m/2 when d² ∣ m with d ≥ 2.
- Residue-class reduction: if M ∣ N then f(N) ≤ f(M)·N/M.
- Lower bounds from injectivity on a progression (squaring is injective on 3j + 1 mod 3^k).
- Close with parity arguments and a strict inequality for composite odd m.

**Pitfall.** The sibling A123365 stalled on exact prime-power formulas (c(q^e) = q^e holds only for e = 1).
This method should be the first thing to try when A123365 is restarted.
