# Minimal counterexample with strict local inequalities

**Origin.** Drafted 2026-11-05 from the OpenAI mathematics manuscript collection (github.com/openai/math, snapshot 2026-10-26), families OAI 173, OAI 189, OAI 310. Paraphrased from abstracts and skimmed proofs; not yet used on a problem in this repo. Confidence that this is one technique: medium (173 and 189 read from PDFs; 310 from abstract)

**Method.** Take a counterexample minimal in vertices, then arcs (or group order). Minimality yields strict local inequalities on every proper substructure (173: a strict second-neighbourhood deficit for every proper subset; 189: the graph is expanding) or restricts the structure to a short list (310, via known reductions). Blow-ups or extremal choices (maximise pair families, BFS distance layers) then contradict the inequalities, or the residual cases are finitely many and each is excluded by a program. A finished argument has the minimality lemma, the extremal/structural step, and the case certificate if any.

**Fit to small problems.** yes: elementary and finite; the 189 pattern (proof cuts to a few thousand finite cases, programs close them) fits small Ramsey numbers and Guy graph questions.

**Lean examples (OpenAI repo).** `lean/OAI/Combinatorics/SecondNeighborhood`, `lean/OAI/Combinatorics/Ramsey`
